# Unsupervised Language Analytics Engine for Macroeconomic Regime Tracking

## Project Overview
The release of Federal Open Market Committee (FOMC) meeting minutes is one of the most anticipated events in global financial markets. It provides a crucial window into the committee's macroeconomic outlook and future monetary policy trajectory, directly driving global interest rates, mortgage yields, corporate investment horizons, and consumer credit pricing.

However, manually digesting dense, multi-page central bank transcripts filled with administrative boilerplate is highly inefficient. 

This project implements an end-to-end **Natural Language Processing (NLP) data pipeline** that automates the collection, normalization, and unbiased mathematical profiling of FOMC minutes. By bypassing human-curated sentiment dictionaries, the engine extracts an objective, time-series "Policy Language Shift" feature directly from raw unstructured text data.

## System Architecture

### 1. The Extraction & Normalization Pipeline
The first module acts as an automated data ingestion engine that handles web mining and text sanitization:
* Programmatically connects to the Federal Reserve central archive to extract raw text from 44 historical meeting minutes.
* Separates policy text from web clutter, strips out administrative boilerplate, and captures chronological calendar release dates.
* Normalizes the text into lowercase, addresses spacing artifacts, and applies a regex filter targeting standalone digits and punctuation.

### 2. The Analytical & Mathematical Engine
The second module handles structural text feature engineering using standard machine learning libraries (`scikit-learn`):

#### A. TF-IDF Vectorization (The Word Filter)
The model converts words into statistical importance weights. It multiplies **Term Frequency (TF)**—how often a word appears in a specific meeting—by **Inverse Document Frequency (IDF)**—which penalizes and suppresses generic background noise words (like *"meeting"*, *"federal"*, or *"economic"*) that appear in almost every document. This process instantly amplifies unique, cycle-specific economic keywords (like `tariffs`, `banking`, or `inflation`).

```python
from sklearn.feature_extraction.text import TfidfVectorizer

vectorizer = TfidfVectorizer(
    stop_words=custom_stop_words, 
    max_df=0.85,
    token_pattern=r'\b[a-zA-Z]{3,}\b' # Preserves financial terms like CPI/GDP
)
tfidf_matrix = vectorizer.fit_transform(all_texts)
```

#### B. Pairwise Cosine Similarity & Language Shift % (The Comparison Scale)
Because FOMC transcripts vary significantly in length from meeting to meeting, the model treats each text profile as a high-dimensional geometric arrow (vector) and calculates the **cosine of the angle between consecutive arrows**. This step eliminates length distortions and isolates true topic proportions:
* A score of **1.0 (0° angle)** implies a 100% identical tone profile from the previous meeting.
* A score of **0.0 (90° angle)** implies zero thematic alignment.

To turn this geometric alignment score into an intuitive asset management signal, the engine translates it into a **Language Shift Percentage**:

```python
from sklearn.metrics.pairwise import cosine_similarity

# Extract geometric alignment distance matrix
similarity_score = cosine_similarity(vec_prev, vec_curr)

# Convert alignment into a true Language Shift Index
true_change_percentage = (1 - similarity_score) * 100
```

## Key Metrics & Commercial Utility

### The Historical Baseline Mean
By aggregating all shift scores, the engine establishes a **Historical Baseline Mean of 52.10%**. This represents the Federal Reserve's normal pace of linguistic evolution during steady economic cycles. 

### Quantitative Warning Signals
When the vocabulary displacement score spikes significantly above the 52.10% ceiling, it serves as a leading macro risk indicator. It proves that an unexpected economic or geopolitical shock has forced the committee to structurally rewrite its narrative, signaling upcoming multi-asset volatility and immediate re-pricing across global yield curves.
